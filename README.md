# Unemployment U.S. Analysis

## Project Overview

An Exploratory Data Analysis project analyzing unemployment patterns across different periods and geographical regions in the United States.
Through data cleaning, preprocessing, statistical analysis, and visualization, this project aims to uncover hidden trends, identify high- and low-unemployment regions,
analyze monthly and annual patterns, and answer meaningful business questions

## Objectives
Understand unemployment trends over time.
Compare unemployment across regions.
Identify areas with relatively high and low unemployment.
Analyze major increases and decreases.
Identify temporal and regional patterns.

## Dataset

U.S. unemployment dataset containing geographical information, time-related fields, unemployment rates,  and unemployment-related measures.

## Analysis Performed
Data inspection and preprocessing.
Missing-value and duplicate analysis.
Date and geographical field standardization.
Summary statistics.
Regional aggregation.
Time-based trend analysis.
High- and low-unemployment comparisons.
Distribution analysis.
Visualizations

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Kaggle Notebook

## Key Skills

Time-Series Analysis, GroupBy, Aggregation, Regional Analysis, Statistical Analysis and Visualization.
